# Бюджет ремонтов по участкам на 2026 год

## 1. Назначение

1. Документ устанавливает годовой бюджет ремонтов оборудования по участкам и статьям.
2. Сведения конфиденциальны и предназначены только для работников финансовой службы.

## 4. Порядок изменения

1. Перераспределение средств между статьями согласует финансовый директор.
2. Превышение годового бюджета участка не допускается без решения генерального директора.
