# Положение об оплате труда работников карьеров

## 1. Общие положения

1. Положение устанавливает должностные оклады и размеры премий работников участков «Карьер-1» и «Карьер-2».
2. Сведения Положения конфиденциальны и предназначены только для работников службы персонала.

## 2. Оклады и премии

| Должность | Оклад, руб. в месяц | Премия, % оклада |
|---|---|---|
| Машинист экскаватора | 156 750 | 40 |
| Водитель карьерного самосвала | 165 150 | 15 |
| Горный мастер | 133 950 | 20 |
| Механик участка | 226 750 | 40 |
| Диспетчер горных работ | 216 250 | 25 |
| Слесарь по ремонту горного оборудования | 215 750 | 25 |
| Начальник участка | 126 650 | 20 |

## 3. Порядок начисления

1. Премия начисляется ежемесячно при выполнении плана добычи участком и отсутствии нарушений требований охраны труда.
2. Размер премии снижается по решению директора по персоналу на основании представления начальника участка.
3. Оклады пересматриваются один раз в год.
