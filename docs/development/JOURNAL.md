## Как устроена проверка ИИ

1. Сначала документ, потом код: агент пишет по записанным решениям и критериям приёмки, а не по пересказу.
2. Утверждения о внешнем мире — цены, возможности сервисов — проверяются по первичному источнику, а не по памяти модели.
3. Документы и код проходят ревью вторым агентом с чистым контекстом, который не видел обсуждения и не знает, почему принято то или иное решение. Ревью идёт кругами: правки по находкам проверяет новый агент; цикл останавливается на первом круге без критических и существенных находок, чтобы не платить за бесконечную полировку мелочей.
4. Последнее слово за человеком: слияние только после его ревью.
