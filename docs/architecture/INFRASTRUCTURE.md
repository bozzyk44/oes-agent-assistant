# Инфраструктура и лимиты

Где работает развёрнутый стенд и в какие ресурсы он обязан укладываться. Почему выбрано именно так — в [DECISIONS.md](DECISIONS.md), решение 4.

Стенд в облаке — дополнение. Сервис, заглушка ТОиР и PostgreSQL поднимаются командой `docker compose up` на любой машине без облака; проверяющие запускают их у себя.

## Состав

```
Интернет ── публичный IP ── облачный сервер VDS1 (Selectel, ru-7)
                              ├─ сервис ассистента (FastAPI)
                              ├─ заглушка ТОиР
                              ├─ PostgreSQL
                              └─ LGTM (отдельный профиль compose)

сервис ассистента ── HTTPS ── ИИ-роутер Selectel ── модель
```

Всё работает в контейнерах на одной машине. Модель — внешняя, по API.

## Лимиты сервера

| Ресурс | Лимит | Откуда |
|---|---|---|
| Серверов | 1 | решение 4 |
| vCPU | 4, разделяемые: низкий приоритет процессора (`cpu_shares` 10) | конфигурация `VDS1.4-8192-80` |
| RAM | 8 ГБ | конфигурация |
| Диск | 80 ГБ, локальный, входит в конфигурацию | конфигурация |
| Дисковые операции | чтение 12 800 операций/с, запись 6 400 операций/с, 320 МБ/с суммарно | конфигурация |
| Дополнительные тома | 0 | решение 4 |
| Публичные IP | 1 | решение 4 |
| GPU | 0 | решение 4 |
| Управляемые сервисы: базы данных, балансировщики, Kubernetes | 0 | решение 4 |

Что из этого следует:

1. **Диск локальный и исчезает вместе с сервером.** На нём нет ничего невосстановимого: `data/` лежит в репозитории, схема базы создаётся миграциями, состояние сессий на стенде — тестовое.
2. **Процессор разделяемый.** Задержку хода на стенде определяет модель, а не сервер, но замеры задержки для `EVAL.md` показательны только при одиночном прогоне без параллельной нагрузки.
3. **Вторую машину не добавляем.** Если стек не помещается в 8 ГБ, отключается профиль наблюдаемости, а не растёт сервер.

## Бюджет памяти

Плановое распределение 8 ГБ. Значения задаются ограничениями памяти контейнеров в compose и уточняются по факту первого запуска.

| Компонент | Лимит памяти |
|---|---|
| Сервис ассистента | 1 ГБ |
| Заглушка ТОиР | 256 МБ |
| PostgreSQL | 1 ГБ |
| LGTM: Loki, Grafana, Tempo, Mimir и сборщик | 3,5 ГБ |
| Система и запас | остаток, около 2,2 ГБ |

## Лимиты стоимости

Цены на 2026-10-12, с НДС.

| Статья | Цена |
|---|---|
| Сервер `VDS1.4-8192-80` | 1,51 ₽ в час |
| Публичный IP | 0,26 ₽ в час |
| Итого за инфраструктуру | 1,77 ₽ в час, около 1 290 ₽ за месяц непрерывной работы |
| Исходящий трафик | около 0,9 ₽ за ГБ |
| Модель | за токены; по основной модели-кандидату — 11,43 ₽ за 1 млн токенов входа и 43,17 ₽ за 1 млн токенов выхода |

Правила:

1. Сервер существует, только пока нужен стенд. После сдачи и разбора он удаляется вместе с публичным IP: остановленный сервер продолжает занимать оплачиваемые диск и адрес.
2. На ключе ИИ-роутера выставляется лимит расхода в панели. Ключ — только в `.env` на сервере и локально.
3. Цена хода ограничена бюджетом хода из задания: не больше 24 000 токенов входа. При ценах основной модели-кандидата это не больше 0,28 ₽ за вход одного хода.

## Доступ

| Что | Как |
|---|---|
| Вход на сервер | SSH по ключу, без пароля |
| API Selectel | Сервисный пользователь с ролью `member` в одном проекте; токен выдаётся на сутки и перевыпускается по идентификатору и паролю |
| Модель | Ключ ИИ-роутера в `MODEL_API_KEY`, адрес в `MODEL_BASE_URL`, модель в `MODEL_NAME` |
| Секреты | Только в `.env`, который не попадает в репозиторий |

Наружу открыты SSH и порт сервиса ассистента. Заглушка ТОиР и PostgreSQL наружу не публикуются. Интерфейс Grafana открывается через SSH-туннель.
