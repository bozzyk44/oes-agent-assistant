# Инфраструктура и лимиты

Где работает развёрнутый стенд и в какие ресурсы он обязан укладываться. Почему выбрано именно так — в [DECISIONS.md](DECISIONS.md), решения 4, 8 и 9.

Стенд в облаке — дополнение. Сервис, заглушка ТОиР и PostgreSQL поднимаются командой `make run` на любой машине без облака; проверяющие запускают их у себя.

## Состав

```
Интернет ── публичный IP ── сервер в Cloud.ru Evolution
                              ├─ сервис ассистента (FastAPI)
                              ├─ заглушка ТОиР
                              ├─ PostgreSQL
                              └─ наблюдаемость: один контейнер (отдельный профиль compose)

сервис ассистента ── HTTPS ── ИИ-роутер Selectel ── модель
```

Всё работает в контейнерах на одной машине. Модель — внешняя, по API, у другого провайдера.

## Лимиты сервера

| Ресурс | Лимит | Откуда |
|---|---|---|
| Серверов | 1 | решение 9 |
| vCPU | 2, гарантированная доля 10 % | конфигурация `lowcost10-2-4` |
| RAM | 4 ГБ | конфигурация |
| Диск | 30 ГБ, SSD, сетевой | решение 9 |
| Дополнительные диски | 0 | решение 9 |
| Публичные IP | 1 | решение 9 |
| GPU | 0 | решение 4 |
| Управляемые сервисы: базы данных, балансировщики, Kubernetes | 0 | решение 4 |

Что из этого следует:

1. **На диске нет ничего невосстановимого.** `data/` лежит в репозитории, схема базы создаётся миграциями, состояние сессий на стенде — тестовое. Сервер можно удалить и создать заново одной командой.
2. **Процессор разделяемый.** Время хода определяет модель, а не сервер, но замеры задержки на стенде зависят от соседей по хосту. Задержка для `EVAL.md` снимается на локальном запуске, и в отчёте указано, где она снята.
3. **Сервер не растёт.** Если стек не помещается в 4 ГБ, отключается профиль наблюдаемости.
4. **30 ГБ диска — с запасом, но не безлимит.** Образы контейнеров, база и телеметрия занимают порядка 8–12 ГБ; телеметрия хранится внутри контейнера и не накапливается между пересозданиями.

## Бюджет памяти

Плановое распределение 4 ГБ. Значения задаются ограничениями памяти контейнеров в compose. Факт — `docker stats` после нескольких ходов: сервис, заглушка и PostgreSQL — на стенде 2026-10-15, наблюдаемость — в локальном запуске `make observe` той же сборки, 2026-10-15.

| Компонент | Лимит памяти | Факт |
|---|---|---|
| Сервис ассистента | 768 МБ | около 110 МБ |
| Заглушка ТОиР | 192 МБ | около 60 МБ |
| PostgreSQL | 768 МБ | около 60 МБ |
| Наблюдаемость, `grafana/otel-lgtm:0.34.0` | 1,2 ГБ | 750–770 МБ |
| Обратный прокси, `caddy:2.11.4-alpine` | 128 МБ | около 14 МБ на стенде |
| Система и запас | остаток, около 1 ГБ | — |

Вместе с наблюдаемостью контейнеры занимают около 1 ГБ из 4. Наблюдаемость хранит данные внутри контейнера: после нескольких ходов — около 600 МБ на диске, при пересоздании контейнера они пропадают.

## Лимиты стоимости

| Статья | Цена |
|---|---|
| Сервер с диском и публичным IP | 1 090,68 ₽ в месяц по калькулятору провайдера на 2026-10-13 для диска 20 ГБ; для выбранных 30 ГБ немного больше, по счёту не сверено |
| Чем оплачивается | Бонусами провайдера за привязку карты: 4 000 бонусов начислены. Покрывают ли они диск и публичный IP, по списаниям не сверено |
| Модель | За токены; у основной модели 11,43 ₽ за 1 млн токенов входа и 43,17 ₽ за 1 млн токенов выхода. Прайс роутера — в рублях; в `PRICE_*` по заданию идут доллары, пересчёт по курсу из `EVAL.md` |

Правила:

1. Сервер работает на срок сдачи и разбора и после этого удаляется вместе с диском и публичным IP.
2. На ключе ИИ-роутера выставляется лимит расхода в панели. Ключ модели лежит в `.env` локально и на сервере. Ключ сервисного аккаунта облака на сервер не копируется: он нужен только Terraform.
3. Цена хода ограничена бюджетом хода из задания: не больше 24 000 токенов входа. При ценах основной модели это не больше 0,28 ₽ за вход одного хода.

## Доступ

| Что | Как |
|---|---|
| Вход на сервер | SSH по ключу, без пароля |
| API Cloud.ru | Ключ сервисного аккаунта; токен выдаётся на час |
| Модель | Ключ ИИ-роутера в `MODEL_API_KEY`, адрес в `MODEL_BASE_URL`, модель в `MODEL_NAME` |
| Секреты | Только в `.env`, который не попадает в репозиторий |

Наружу открыт SSH. С профилем `proxy` — ещё 80 и 443 для обратного прокси с паролем: страница и API по имени и по HTTPS (решение 17). Порт сервиса ассистента по умолчанию закрыт и открывается для заданных адресов: у сервиса нет аутентификации, заголовок `X-User-ID` считается доверенным. Правила задаёт группа безопасности облака — единственный внешний барьер, потому что Docker публикует порты в обход экрана на самом сервере. Заглушка ТОиР, PostgreSQL и наблюдаемость наружу не публикуются. Интерфейс Grafana открывается через SSH-туннель.
